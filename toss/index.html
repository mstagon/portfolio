02정량 평가 · 교차 검증

생성 결과물 품질 측정

생성 결과물을 점수로 다루는 루프를 두 곳에 적용했습니다. 문서는 페르소나 리뷰어 5명이 독립 채점한 뒤 토론과 사회자 합의로 점수를 내고, 편집 에이전트가 수정한 뒤 다시 채점합니다. 기준 점수나 최대 회차까지 반복하고 GPT가 교차 채점합니다. 제품은 출시 전에 여러 에이전트로 감사해 교차 검증을 통과한 결함만 확정했고, Claude와 Codex가 같은 줄을 지적한 것만 출시 차단 항목으로 정했습니다.

03Design-to-code · 디자인 토큰

디자인에서 코드까지

디자인을 눈으로 보고 옮기면 간격과 폰트, 색이 조금씩 어긋납니다. Figma MCP로 토큰과 측정값을 먼저 추출하고, 구현한 화면의 스크린샷을 Figma 이미지와 대조해 차이를 수치로 지목해 수정하는 루프를 스킬로 정형화했습니다. 일치한 렌더는 golden 테스트로 고정해 회귀를 막습니다. 앱에서는 디자이너의 Tokens Studio JSON에서 Dart 상수를 자동 생성하는 토큰 파이프라인을 구축했고, Figma 디자인 값으로 Next.js와 Flutter 코드를 생성하는 추출기도 개발했습니다.

04CI/CD · 개발 인프라 · 관측

배포 파이프라인과 검증 게이트

서버는 CodePipeline에 승인 두 단계와 Migrate 전용 단계를 두어 마이그레이션을 같은 이미지로 한 번만 실행하고, 실패하면 배포 단계로 진행하지 않습니다. 등록에서 빠진 마이그레이션이 배포 후 500 오류로 드러나는 일이 네 차례 반복되자, 파일과 등록 배열을 1:1 대조하는 테스트를 GitHub Actions 가드로 추가해 머지 전에 차단합니다. 앱은 Codemagic 워크플로 8개로 스토어 빌드와 Shorebird 패치를 실행하고, 빌드 번호는 스토어와 Shorebird 중 큰 값에 1을 더해 부여합니다. 웹게임은 화면 조합 검사를 CI 게이트로 두어 화면 잘림을 머지 전에 발견합니다.

05플랫폼 SDK · 팀 개발 표준
