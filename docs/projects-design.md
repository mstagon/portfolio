# 프로젝트 아카이브

- 경로: `/projects/`, 각 프로젝트는 `/projects/<slug>/`에 독립된 정적 페이지를 둔다.
- 아트 방향: 과거 `mstagon/cms` develop의 어두운 배경·민트·보라 계열을 참고한 사이버 아카이브. 기존 메인 페이지의 레이아웃은 유지한다.
- 우선순위: 프로젝트 구분 → 직접 맡은 역할 → 판단과 구현 → 화면 → 결과. 숫자·터미널 장식보다 실제 이미지와 본문에 면적을 쓴다.
- 토큰: 배경 `#090d16`, 표면 `#101722`, 본문 `#edf2f8`, 보조 `#a3afbf`, 민트 `#a1f6ce`. Pretendard 본문, JetBrains Mono 메타데이터.
- 구성: 단일 H1, 검색·회사/개인/팀 필터, 3/2/1열 그리드. 상세는 목차와 본문으로 나누고 모바일에서 한 열로 읽는다.
- 상호작용: 키워드와 분류의 교집합, URL 상태, 이미지 확대, 키보드 포커스, reduced-motion. 콘텐츠는 JavaScript 없이도 모두 접근 가능하다.
- 검증: 34개 원문 범위, 정확한 분류·이미지 경로·정적 링크, 검색/빈 결과/히스토리, 모바일 넘침, 이미지 모달·키보드, 기존 경로 보존.
