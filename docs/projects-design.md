# 프로젝트 아카이브

- 경로: `/projects/`, 각 프로젝트는 `/projects/<slug>/`에 독립된 정적 페이지를 둔다.
- 아트 방향: 과거 프로젝트 콘텐츠를 복원하되, 메인 포트폴리오의 차콜·오렌지 디자인 시스템을 공유한다. 기존 메인 레이아웃은 유지한다.
- 우선순위: 프로젝트 구분 → 직접 맡은 역할 → 판단과 구현 → 화면 → 결과. 숫자·터미널 장식보다 실제 이미지와 본문에 면적을 쓴다.
- 토큰: `css/design-tokens.css`를 메인과 함께 사용. 배경 `#0b0b0d`, 표면 `#111114`, 본문 `#eeede8`, 보조 `#b8b7b1`, 오렌지 `#ff6a2b`. Pretendard 본문, JetBrains Mono 메타데이터. 공통 여백·18px 카드·알약형 버튼/태그.
- 구성: 단일 H1, 검색·회사/개인/팀 필터, 3/2/1열 그리드. 상세는 목차와 본문으로 나누고 모바일에서 한 열로 읽는다.
- 상호작용: 키워드와 분류의 교집합, URL 상태, 이미지 확대, 키보드 포커스, reduced-motion. 콘텐츠는 JavaScript 없이도 모두 접근 가능하다.
- 검증: 23개 선별 프로젝트 범위, 정확한 분류·이미지 경로·정적 링크, 검색/빈 결과/히스토리, 모바일 넘침, 이미지 모달·키보드, 기존 경로 보존.
