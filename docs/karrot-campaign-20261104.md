# 당근 Frontend 지원 페이지 변경

대상 공고: https://careers.daangn.com/jobs/role/8043875003/
확인일: 2026-11-04

기존 Engagement 파트 전용 페이지를 산업기능요원 Frontend 통합 채용에 맞춰 재구성합니다. 공고는 React·TypeScript 인앱 웹, 사용자 흐름, 문제 정의부터 운영까지의 책임, 제품 실험, AI 제품·개발 도구와 협업을 요구합니다. 조직은 면접 이후 제안되는 공고이므로 특정 파트 이름을 헤더에서 제거합니다.

## 선정

1. 미네르바: 웹·SDK 책임 분리, 상태와 재시도, 재진입·백그라운드 동작. 팀의 게임·서버 기여와 본인 역할 구분.
2. 마블워크 CMS: Next.js 운영 제품, 대상 미리보기부터 발송·결과 확인, 고객 대응과 당첨자 안내.
3. 마블워크 보상 누락: 한 달간 전체 흐름 추적, 원인별 수정, 30일 복구 지급 451건.
4. 제품 실험: 비회원 체험 기획·리드, 지표 정의와 무작위 배정. 관찰한 코호트 차이를 인과 효과로 표현하지 않음.
5. Forge Studio: 회사 경력. React UI, 팀 프리셋 공유와 CLI 실행 제어, 사람의 검증·승인 경계.
6. OracleX·라피, 웹/모바일 팀 프로젝트. 전체 내용은 개발 아카이브와 연결.

요청 수 38→17, 기본 인증 목록, 커밋·코드 줄 수를 대표 성과에서 제외했습니다. 미확인 GraphQL·SSR·대규모 성능 성과, 입사 가능 날짜를 추가하지 않습니다. A/B는 2026년 10월 자료 기준으로 결과 미확정임을 밝힙니다.

## 화면

기존 밝은 당근 지원 페이지의 디자인을 유지합니다. 흰 배경, `#1a1c20` 본문, `#4d5159` 보조, `#e6e8eb` 구분선, `#ff6f0f` 강조, 글자 강조는 `#c24e00`. Pretendard, 1040px 본문, 30px 제목/15~17px 본문. 회사 → 서비스 → 작업의 계층을 유지하고 실제 화면과 책임 구조를 보여 줍니다.

아카이브 링크는 모바일에서도 항상 보이는 헤더와 소개·프로젝트·푸터에 배치합니다. 스크롤 내비게이션은 페이지 내부 링크만 대상으로 유지해 아카이브 경로를 CSS 선택자로 해석하지 않게 합니다.

## 근거

최신 공고, 같은 날짜에 작성한 당근 이력서·포트폴리오 원문, 기존 공개 페이지의 실험 정의, 아카이브에서 검토한 웹·SDK·CMS·보상·Forge 구현 근거를 사용했습니다. 새롭게 서비스 성과를 집계하거나 제품 테스트를 실행한 것은 아닙니다.
