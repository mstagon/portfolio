- 회사 7개, 개인·사이드 17개, 팀 10개: 총 34개 프로젝트와 목록 1개.
- 이전 사이버 포트폴리오의 10개 프로젝트와 별도 피부 병변 분류 프로젝트를 포함.
- Forge Studio 회사 분류, DOSS 담당 범위, 미네르바 팀 역할, 테스트 배포·중단 프로젝트의 상태를 검토.
- GitHub 외부 저장소 링크 12개가 유효한 저장소로 응답함을 확인.
- 최신 원격 main `1f9052a`에서 작업. 기존 `karrot`, `backend`, `toss` 페이지 변경 없음.

## 실행한 검증

- `python3 tools/build-projects.py --check`: 생성된 35개 페이지가 데이터와 일치.
- Python unittest 5개: 전체 프로젝트 포함·중복 방지, 역할 분류, 필수 본문, 정적 링크·이미지, JavaScript 없는 콘텐츠.
- Chromium 브라우저: 분류와 검색 교집합, 한글 IME, 빈 결과·초기화, URL 복원·뒤로가기, 이미지 모달·Escape·포커스 복원.
- 320·390·768·1440px에서 목록과 대표 상세 화면 확인. 상세 페이지 34개 및 이미지 경로 확인. 새 페이지 가로 넘침·자바스크립트 오류·로컬 HTTP 오류 없음.
- JavaScript를 끈 상태에서 전체 카드와 상세 링크 작동 확인.
- 데스크톱·모바일 실제 스크린샷을 확인. 지연 로드 이미지는 디코딩 완료 후 캡처.
- 기존 메인의 320px 가로 넘침은 원격 원본과 같은 370px로, 이번 변경으로 증가하지 않음. 새 아카이브는 320px에서 넘침 없음.
