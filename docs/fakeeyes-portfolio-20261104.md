# 페이크아이즈 지원 포트폴리오

대상: https://www.jobkorea.co.kr/Recruit/GI_Read/50151035

2026-11-04에는 원문 재접속이 실패해, 앞서 같은 공고에서 보관한 상세 본문과 검토 자료를 사용했다. 웹 풀스택 역할의 DB·API, 운영 대시보드, 외부 도구·SDK 연동, 진단·장애 대응과 AI 개발 도구 활용에 맞춰 사례를 골랐다. 사용자가 직접 경험이 없다고 답한 MariaDB 운영, TCP/UDP 직접 구현, RTSP/WebRTC는 경험으로 추가하지 않았다.

## 결과물

- `/fakeeyes/`: 지원용 웹 포트폴리오. 다른 지원 페이지와 기존 `/backend/`는 보존한다.
- `/fakeeyes/choi-minseok-portfolio.pdf`: 같은 원문에서 출력한 8쪽 제출용 PDF.
- `fakeeyes/index.html`: 콘텐츠 원본. `tools/export-fakeeyes.mjs`로 PDF 재생성.
- 기존 정장 사진 `img/profile-suit.webp`를 웹·PDF 첫 장에 배치.
- 헤더·소개·마지막 페이지에 개발 아카이브 연결. 이력서에서 사용하기 좋은 고정 주소를 제공한다.

## 선정과 표현

1. 보상 누락: 한 달간 앱·광고사·서버를 대조한 세 원인, 수정 판단, 30일 복구 지급 451건. 사람 수나 전체 성공률로 바꾸지 않는다.
2. 쿠폰: 외부 응답 유실과 명시적 거절을 분리하고 잔액 잠금·대기 거래·트랜잭션 밖 외부 호출을 설명한다. 운영자 확인이라는 대가를 포함한다.
3. CMS: 정책 변경, 대상 확인·테스트·예약 발송, 고객 이력·포인트 조정, 당첨 안내의 실제 업무를 중심으로 한다.
4. EB: 사용자·운영 API와 워커의 실행 경계, SQS 실패 응답, 기존 환경 파일 때문에 predeploy에 도달하지 못했던 경로를 다룬다. 무중단·exactly-once 성과로 확대하지 않는다.
5. 미네르바·OracleX: 플랫폼과 호스트의 책임 분리, 단계별 재시도, 중단 사유·세션, 네이티브 동작 계약 이식. 게임·서버와 원본 SDK의 동료 기여를 명시한다.
6. Forge Studio: 회사 제품. JSON 프리셋 공유·적용, CLI 실행·승인·중지와 학습 기록의 검토·적용을 기능으로 설명한다.
7. Teamo·PHC·라피·레거시 MCP를 간결히 소개하고 23개 전체 프로젝트로 연결한다.

커밋 비율, API 요청 38→17, 기초 인증 목록, AI 부팀장 표현은 사용하지 않는다. 기존 근거 조사와 승인된 이력서의 사실을 재구성했으며 새 운영 수치를 측정한 것은 아니다.

## 디자인·검증

메인과 아카이브의 공통 색·서체 토큰을 사용한다. 웹은 차콜·주황, PDF는 흰 바탕과 동일한 계층·강조로 출력한다. 콘텐츠는 JavaScript 없이 읽고 이동할 수 있다.

- 정적 링크·이미지·해시 목적지 확인, 기존 정적 테스트 9개와 아카이브 24페이지 검사 통과.
- 320·390·768·1024·1440px에서 가로 넘침, 사진, 6개 사례 이동, 아카이브 왕복, PDF 다운로드와 이미지 요청 검사 통과.
- PDF 8쪽, 사진·본문·표·도식·페이지 번호를 렌더링해 확인. PDF 외부 링크에 localhost 주소가 남지 않음을 검사.
- 당근·페이크아이즈 이력서의 HTML·PDF에 같은 사진을 넣고 링크를 각각 `/karrot/`, `/fakeeyes/`로 교체. `/projects/`를 추가. 두 이력서 모두 2쪽 및 하단 여백 검사를 유지.
- 당근 기존 6쪽 PDF에도 사진과 `/karrot/`, `/projects/` 링크를 반영.
- 원본 파일·생성기는 각 문서의 `working/before_links_photo_20261104/`에 보존.
- 이번 사이트 작업에서 이미 승인한 직접 내용·코드 검토와 화면 검증으로 게시한다.

## 재생성

저장소 루트에서 로컬 정적 서버를 4318 포트로 실행한 다음:

```sh
node tools/export-fakeeyes.mjs
node tests/fakeeyes_browser.mjs
```

Playwright가 전역 모듈 경로에 없다면 `PLAYWRIGHT_MODULE`에 설치된 `playwright/index.mjs`의 절대 경로를 지정한다. `CHROME_PATH`, `PORTFOLIO_URL`로 브라우저 실행 파일과 로컬 주소를 바꿀 수 있다.
