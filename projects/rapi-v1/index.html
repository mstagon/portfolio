01 / OVERVIEW

어떤 프로젝트인가요?

Electron 데스크톱과 에이전트 실행부를 분리하고, 능동적인 대화와 도구 사용을 실험했습니다. 가벼운 상호작용은 로컬 모델, 긴 대화는 외부 API로 나누는 방향을 시도했습니다.

  1. 01데스크톱 인터페이스
  2. 02로컬 모델 · 외부 API
  3. 03에이전트 실행부

02 / ENGINEERING

구현과 판단

01

모델 학습과 제품 동작을 함께 실험

Qwen2.5-3B를 바탕으로 MLX LoRA와 합성 선호 데이터의 DPO 학습을 실험하고 Ollama로 실행했습니다. 데스크톱과 서버에서 실행부를 공유할 수 있게 분리했습니다.

02

학습 실험에서 지속되는 작업으로 초점 이동

모델 학습과 런타임 실험에 집중했던 경험을 바탕으로, 후속 라피에서는 세션·진행 상태·승인·기록의 제품 흐름에 더 무게를 뒀습니다. 규칙과 이벤트 구조를 다음 버전에 이어 갔습니다.

03 / OUTCOME

결과와 범위

2026년 5월까지의 초기 버전입니다. 실행부 분리와 규칙·이벤트 설계 경험을 후속 라피의 서버 세션 구조에 이어 갔습니다.
