01 / OVERVIEW

어떤 프로젝트인가요?

ISIC 2019의 공개 피부 병변 이미지를 활용해 7개 범주를 분류하는 모델과 앱 연동을 실험했습니다. 전공 소모임에서 진행한 학습용 프로젝트입니다.

  1. 01공개 이미지 데이터
  2. 02모델 비교 · 분류
  3. 03앱 결과 표시

02 / ENGINEERING

구현과 판단

01

하나의 모델 대신 여러 접근 비교

CNN 분류와 Autoencoder·PCA·MLP 기반 접근을 비교하고 GAN 활용도 실험했습니다. 모델 출력이 앱의 결과 표시로 이어지는 흐름을 다뤘습니다.

03 / INTERFACE

프로젝트 화면

04 / OUTCOME

결과와 범위

전공 소모임 대상을 수상했습니다. 의료 진단 제품이나 임상 검증 결과가 아닌 학습용 이미지 분류 프로젝트입니다.
