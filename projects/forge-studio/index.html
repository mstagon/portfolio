01 / OVERVIEW

어떤 프로젝트인가요?

개인별 파일과 명령에 흩어진 AI 개발 환경을 팀이 함께 다룰 수 있도록 만든 도구입니다. 프로젝트의 에이전트·명령·스킬·훅과 인식 가능한 규칙을 프리셋으로 내보내고, 다른 팀원이 가져와 프로젝트에 적용할 수 있게 했습니다.

  1. 01프로젝트 설정 · 규칙
  2. 02공유 프리셋 · 워크플로
  3. 03실행 · 검토 · 승인

02 / ENGINEERING

구현과 판단

01

하네스 설정을 팀이 교환할 수 있는 기능으로

에이전트, 스킬, 훅과 프로젝트 규칙을 GUI에서 관리하고 JSON 프리셋으로 가져오기·내보내기·적용을 연결했습니다. 잘 작동하는 개발 설정을 팀원이 재사용하도록 설계했습니다.

02

명령을 실행한 뒤의 과정까지 보이게

단계별 CLI 실행, 출력 확인, 승인과 중지를 화면에 연결했습니다. 후속 버전에서는 격리된 Git worktree를 사용하는 팀 작업과 모델 간 교차 검수를 다뤘습니다.

03

학습 기록을 자동 규칙으로 무조건 바꾸지 않기

프로젝트별 시행착오를 저장·검색하고 반복된 내용을 규칙 후보로 모았습니다. 사용자가 확인하고 적용해야 프로젝트 규칙에 반영되도록 했습니다.

04

팀의 하네스 철학을 실행 경계로

작업 계약과 파일 소유권, 완료 검증, 사람의 승인 지점을 구분했습니다. 에이전트의 실행 속도뿐 아니라 무엇을 맡기고 어떻게 결과를 검증할지를 개발 환경에 담았습니다.

03 / INTERFACE

프로젝트 화면

이미지를 누르면 크게 볼 수 있습니다.

04 / OUTCOME

결과와 범위

팀원이 프리셋 파일을 주고받아 개발 설정을 적용하고, 작업 실행과 검토를 화면에서 다룰 수 있게 했습니다. 회사에서 만든 도구이며 후속 v2 코드는 공개 저장소에서 볼 수 있습니다.
