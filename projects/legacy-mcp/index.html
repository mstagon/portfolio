01 / OVERVIEW

어떤 프로젝트인가요?

Java·Spring Boot·MyBatis 기반 커머스 코드를 반복 탐색하는 비용을 줄이기 위한 도구입니다. 정적 분석 결과를 SQLite에 담고 MCP, HTTP, CLI와 웹 화면에서 같은 인덱스를 읽도록 구성했습니다.

  1. 01Java · SQL · 문서
  2. 02관계 분석 · SQLite
  3. 03MCP · HTTP · CLI

02 / ENGINEERING

구현과 판단

01

코드와 SQL을 따로 읽지 않도록

Java 구문 분석, MyBatis XML 분석, 문서 전문 검색을 연결했습니다. 기능과 채널 구현의 관계를 묶어 에이전트가 매번 저장소 전체를 다시 읽지 않고 필요한 맥락을 찾게 했습니다.

02

사람과 에이전트가 같은 자료를 사용

MCP stdio, HTTP API, 웹 GUI와 CLI를 하나의 인덱스 위에 구성했습니다. 분석 결과를 특정 에이전트의 대화 기록에만 남기지 않았습니다.

03 / OUTCOME

결과와 범위

레거시 탐색 결과를 재사용 가능한 개발 도구로 만든 사내 프로젝트입니다.
