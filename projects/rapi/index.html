01 / OVERVIEW

어떤 프로젝트인가요?

서버가 에이전트 세션을 유지하고 앱과 웹이 같은 작업 상태를 보는 개인 에이전트입니다. 작업·일정 관리와 도구 실행을 연결하고, rapibrain이 작업 기록을 Markdown 저장소에 모아 다음 작업에서 조회하도록 했습니다.

  1. 01앱 · 웹 요청
  2. 02서버 세션 · 도구 실행
  3. 03작업 기록 · rapibrain

02 / ENGINEERING

구현과 판단

01

클라이언트가 바뀌어도 이어지는 작업

초기 OpenAI 호환 CLI 브리지에서 서버 세션 중심 구조로 확장했습니다. 스트리밍 응답뿐 아니라 진행 상태·취소·승인과 여러 클라이언트의 동기화를 다뤘습니다.

02

이전 작업의 맥락을 다시 찾는 메모리

개발 작업과 Git 기록을 주기적으로 수집해 Markdown 저장소에 남겼습니다. 에이전트는 MCP로 필요한 기록을 조회하며, 대화 한 번의 컨텍스트에만 의존하지 않게 했습니다.

03

실행 권한과 자기 수정의 경계

에이전트가 스스로 권한 설정을 바꾸지 못하도록 하고 감사 기록과 비상 중지를 뒀습니다. 자기 코드 수정도 변경안을 만든 뒤 사람이 승인하는 흐름으로 나눴습니다.

03 / OUTCOME

결과와 범위

대화형 도구에서 지속되는 작업 시스템으로 확장한 개인 프로젝트입니다. 설계 과정은 개발 글에 정리했습니다.
