01 / OVERVIEW

어떤 프로젝트인가요?

대학 e-Campus의 강좌와 수강 진도를 조회하는 데스크톱 프로그램입니다. 로그인 세션으로 필요한 페이지를 읽고 강좌별 정보를 표 형태의 GUI에 모았습니다.

02 / ENGINEERING

구현과 판단

01

로그인 여부를 실제 응답으로 확인

세션을 유지하며 페이지를 요청하고 사용자 정보가 있는지 확인했습니다. 로그인 실패 상태를 정상 강의 목록으로 처리하지 않도록 했습니다.

02

반복 조회를 한 번의 화면으로

강좌별 진도 정보를 파싱해 Treeview와 Combobox에 정리했습니다. 직접 겪던 반복 확인 작업을 줄이기 위해 만든 도구입니다.
