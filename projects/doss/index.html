01 / OVERVIEW

어떤 프로젝트인가요?

종목 정보와 관심 목록을 모바일 화면에서 살펴보는 팀 프로젝트입니다. 로그인, 설정, 관심 종목과 관련 API를 맡고 외부 금융 API의 호출 경로를 개선했습니다.

  1. 01종목 조회 · 관심 목록
  2. 02갱신 시점 확인
  3. 03외부 API · DB 캐시

02 / ENGINEERING

구현과 판단

01

화면 조회마다 외부 시세를 요청하지 않도록

마지막 갱신 시점을 기준으로 데이터를 갱신하고 일반 조회는 DB에 저장된 값을 읽도록 했습니다. 외부 API 호출과 사용자 조회를 분리했습니다.

02

재시작해도 유지되는 로그인 잠금

로그인 5회 실패 시 5분 잠금을 적용하고 상태를 저장했습니다. 프로세스를 재시작했다고 잠금이 초기화되지 않도록 처리했습니다.
