01 / OVERVIEW

어떤 프로젝트인가요?

Ethereum, Tron, BNB, Polygon, Arbitrum 거래 인덱서와 지갑 관계 분석, 행동 점수 모델을 구현했습니다. Next.js의 지갑 입력 화면에서 FastAPI 분석으로 이어지는 구조를 만들고, 거래 흐름·네트워크·클러스터를 보는 화면을 구성했습니다.

  1. 015개 체인 거래
  2. 02지갑 그룹 · 20개 특성
  3. 03모델 점수 · 웹 화면

02 / ENGINEERING

구현과 판단

01

주소별 거래를 지갑 관계로 묶기

직접 송금, 거래소 상호작용, 브리지 이동, 활동 시각과 거래 상대 패턴을 비교했습니다. 신호별 점수를 모아 같은 소유자일 가능성이 높은 지갑 후보를 구성했습니다.

02

수집한 거래를 모델 입력으로 바꾸기

거래 기간·금액·상대방 분산·그래프 특성 등 20개 피처를 구성했습니다. RandomForest·GradientBoosting·LightGBM 앙상블과 규칙 기반 점수기를 구현하고, 학습 모델이 없을 때는 규칙 기반 처리를 사용하도록 했습니다.

03

실험 데이터와 실제 평가 결과를 구분

실제 신용 결과 라벨이 없어 신규·일반·고액·의심·DeFi 사용자라는 5종의 합성 시나리오로 학습 데이터를 구성했습니다. 모델 저장·불러오기와 평가 경로까지 연결하되, 실제 신용평가 성능을 입증한 결과와는 구분했습니다.

04 / OUTCOME

결과와 범위

거래 수집 → 관계 분석 → 점수 계산 → 웹 조회의 전체 흐름을 구성한 프로토타입입니다. 화면은 로컬에서 실행해 확인했으며, 점수 모델은 합성 데이터 기반 실험입니다.
