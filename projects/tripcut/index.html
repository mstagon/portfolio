01 / OVERVIEW

어떤 프로젝트인가요?

드라마 촬영지를 지역과 태그로 찾고 여행 코스를 구성하는 서비스입니다. 장소 검색, 상세와 후기, 즐겨찾기, 코스와 마이페이지를 구현했습니다.

  1. 01지역 · 태그 탐색
  2. 02장소 · 후기 · 즐겨찾기
  3. 03여행 코스

02 / ENGINEERING

구현과 판단

01

웹 탐색을 모바일 앱에 가까운 흐름으로

단계적으로 펼쳐지는 바텀시트와 모바일 상세 화면을 구성했습니다. PWA 홈 화면 설치와 Service Worker의 기본 캐싱을 적용했습니다.

02

서로 다른 서버의 요청을 일관되게

FastAPI 프록시와 Spring Boot 도메인 API를 Axios 모듈로 나누고 인터셉터에서 공통 요청 처리를 정리했습니다.

03 / INTERFACE

프로젝트 화면

이미지를 누르면 크게 볼 수 있습니다.

04 / OUTCOME

결과와 범위

여행 탐색부터 코스 저장까지 모바일 웹의 연속된 흐름을 맡았습니다.
