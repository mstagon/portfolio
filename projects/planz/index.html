01 / OVERVIEW

어떤 프로젝트인가요?

사용자의 고정 일정에 맞춰 취침·기상·낮잠 계획을 세우고 수면 기록을 확인하는 서비스입니다. 루틴 설정, 캘린더, 수면 기록과 앱의 인증·알림 연동을 맡았습니다.

  1. 01고정 일정
  2. 02수면 계획 · 루틴
  3. 03캘린더 · 기록

02 / ENGINEERING

구현과 판단

01

선택한 날짜와 루틴을 서로 독립적으로

캘린더 날짜 변경이 루틴 선택을 덮어쓰지 않도록 상태를 분리했습니다. 월별 조회를 캐시하고 기록 편집 모달과 캘린더 표시를 연결했습니다.

02

기록 화면 밖의 앱 흐름까지

안전한 토큰 저장과 인증 요청을 연결하고 FCM 알림을 적용했습니다. 화면 단위 구현과 앱의 공통 상태를 함께 다뤘습니다.

03 / INTERFACE

프로젝트 화면

이미지를 누르면 크게 볼 수 있습니다.

04 / OUTCOME

결과와 범위

멋쟁이사자처럼 팀 프로젝트로 일정과 수면 루틴의 모바일 UX를 구현했습니다.
