01 / OVERVIEW

어떤 프로젝트인가요?

취업 공고를 찾고 AI 자기소개서 피드백을 받아 지원 일정을 관리하는 웹 서비스입니다. React 화면과 Flask API, OpenAI 연동 및 일정 화면을 구현했습니다.

  1. 01채용 공고 탐색
  2. 02자기소개서 피드백
  3. 03지원 일정 관리

02 / ENGINEERING

구현과 판단

01

AI 응답을 사용자가 읽는 피드백으로

프롬프트와 출력 구조를 정리하고 응답 대기 상태와 피드백 이력을 화면에 연결했습니다. 단순 API 호출 뒤의 사용 흐름까지 구현했습니다.

02

공고 정보를 일정으로 옮기기

기업 이름의 별칭과 키워드를 매칭해 공고를 찾고, 지원 마감 정보를 캘린더 이벤트로 변환했습니다.
