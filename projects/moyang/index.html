01 / OVERVIEW

어떤 프로젝트인가요?

자취방 양도 매물을 지도와 조건으로 탐색하고 채팅으로 연결하는 모바일 서비스입니다. Flutter 앱의 지도·필터·채팅과 공통 API 통신 구조를 개발했습니다.

  1. 01지도 · 조건 필터
  2. 02매물 탐색
  3. 03실시간 채팅

02 / ENGINEERING

구현과 판단

01

현재 보고 있는 지도 범위에 집중

보이는 지도 영역을 기준으로 매물을 요청하고 마커를 클러스터링했습니다. 필터 상태를 중앙에서 관리해 지도와 목록의 선택 조건이 어긋나지 않게 했습니다.

02

연결이 끊겼다가 돌아오는 채팅

STOMP 연결 재시도와 오프라인 메시지 큐를 다루고 화면 상태에 반영했습니다. DTO와 API 클라이언트 생성을 통해 응답 모델의 반복 구현을 줄였습니다.

03 / INTERFACE

프로젝트 화면

이미지를 누르면 크게 볼 수 있습니다.

04 / OUTCOME

결과와 범위

지도 기반 탐색과 실시간 연결의 상태를 앱에서 함께 다룬 경험입니다.
