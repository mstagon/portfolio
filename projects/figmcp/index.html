01 / OVERVIEW

어떤 프로젝트인가요?

Figma의 실제 문서 구조를 개발에 전달하기 위해 Plugin API 기반 로컬 브리지를 만들었습니다. 중간 표현(IR)을 거쳐 Next.js와 Flutter 출력을 생성하고 구조 및 렌더 결과를 나눠 확인했습니다.

  1. 01Figma 라이브 문서
  2. 02공통 IR
  3. 03코드 생성 · 화면 비교

02 / ENGINEERING

구현과 판단

01

추출과 생성을 공통 IR로 분리

특정 프레임워크 코드로 바로 옮기지 않고 레이아웃과 속성을 중간 표현으로 정리했습니다. Next.js를 우선 출력으로, Flutter를 다음 출력으로 연결했습니다.

02

구조 검사와 실제 화면 검사를 분리

IR과 생성 결과의 구조를 먼저 비교하고, 렌더한 스크린샷을 Figma 이미지와 대조했습니다. 플러그인은 localhost 브리지와 통신하도록 범위를 제한했습니다.

03 / OUTCOME

결과와 범위

디자인 데이터를 읽는 단계와 코드 생성·검증 단계를 잇는 사내 개발 도구입니다.
