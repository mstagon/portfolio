01 / OVERVIEW

어떤 프로젝트인가요?

휴대폰 거치와 휴식 시간을 식물 성장으로 연결하는 서비스입니다. NFC로 사용 시작을 인식하고, 타이머와 보상 상태를 Flutter 앱에서 관리했습니다.

  1. 01NFC 거치 인식
  2. 02휴식 시간 · 식물 성장
  3. 03포인트 · 상점

02 / ENGINEERING

구현과 판단

01

불안정한 충전 감지 대신 NFC 사용

무선 충전 여부만으로 거치 상태를 판단하기 어려워 NFC를 시작 신호로 사용했습니다. 센서 선택을 사용자 흐름과 실제 기기 제약에 맞춰 바꿨습니다.

02

화면을 떠나도 일관된 시간과 보상

백그라운드에 머문 시간을 누적하고 복귀 시 타이머 상태를 복원했습니다. 타이머·재화·구매 상태를 분리해 화면 업데이트와 보상 처리가 얽히지 않게 했습니다.

03 / INTERFACE

프로젝트 화면

이미지를 누르면 크게 볼 수 있습니다.

04 / OUTCOME

결과와 범위

NFC 입력부터 휴식 시간 복원, 식물 성장과 포인트까지 사용자의 실제 행동을 모바일 상태에 연결했습니다.
