01 / OVERVIEW

어떤 프로젝트인가요?

오퍼월 웹 화면과 호스트 앱을 연결하는 Flutter SDK입니다. 동료가 작성한 Kotlin·Swift SDK를 바탕으로 공개 API, 인증, JavaScript 브리지, 화면 닫기와 오류 보고를 Dart 중심 구조로 이식했습니다.

  1. 01호스트 앱 · 인증
  2. 02Dart SDK · 네이티브 기능
  3. 03오퍼월 웹 · 브리지

02 / ENGINEERING

구현과 판단

01

래퍼를 넘어 동작 계약을 이식

웹에서 호출하는 7개 브리지 액션, POST 인증 데이터, 광고 식별자 처리와 오류 보고를 분석해 Dart에서 다시 구성했습니다. Android 설치 확인처럼 플랫폼 의존성이 있는 기능은 최소 플러그인으로 남겼습니다.

02

뒤로가기 한 번에 무엇을 닫을지

모달 → 드로어 → 공통 페이지 → 화면 종료 순서를 맞추고 웹의 닫기 처리와 호스트 내비게이션을 연결했습니다. 단순한 WebView 종료로 웹 내부 상태가 건너뛰어지지 않도록 했습니다.

03

페이지 로드와 세션의 경합을 처리

플랫폼별 스크립트 주입 시점, 페이지 재주입, 인증 중 사용자 변경, 해제된 iOS 화면으로 오는 콜백을 다뤘습니다. 실제 서버의 form 전송 계약도 SDK에 반영했습니다.

03 / OUTCOME

결과와 범위

기존 오퍼월을 Flutter 호스트에 연결하는 Dart SDK로 재구성하고, 공개 API와 브리지 동작을 계약 테스트로 확인할 수 있게 정리했습니다.
