01 / OVERVIEW

어떤 프로젝트인가요?

보건소의 예약과 접수, 사용자 기록을 다루는 서비스입니다. 팀이 익숙한 React와 Flutter를 모두 활용할 수 있도록 역할을 나누고 공통 FastAPI 서버에 연결했습니다.

  1. 01React 레이아웃 · 라우팅
  2. 02Flutter 기능 모듈
  3. 03공통 FastAPI

02 / ENGINEERING

구현과 판단

01

서로 다른 프론트엔드 선택을 통합 구조로

React는 전체 레이아웃과 라우팅, Flutter Web은 기능 모듈을 맡도록 경계를 정했습니다. PostMessage로 필요한 이벤트를 전달하고 각 모듈의 라우팅을 분리했습니다.

02

관련 데이터를 읽는 비용을 줄이기

SQLAlchemy 관계 조회에서 반복 쿼리가 생기는 경로를 확인하고 로딩 방식을 조정했습니다. 예약·기록 화면이 필요한 데이터를 가져오는 경로를 API와 함께 다뤘습니다.
