01 / OVERVIEW

어떤 프로젝트인가요?

프로젝트 팀원 모집과 협업을 위한 웹 서비스입니다. Next.js와 NestJS 개발에 참여하고 Docker Compose, Nginx, GitHub Actions로 라즈베리파이 배포 환경을 구성했습니다.

  1. 01팀 모집 · 채팅
  2. 02웹 · API · 데이터베이스
  3. 03ARM 서버 배포

02 / ENGINEERING

구현과 판단

01

개발 장비와 운영 장비의 아키텍처 차이

CI의 x86 환경에서 만든 이미지가 ARM 라즈베리파이에서도 실행되도록 Docker Buildx로 amd64·arm64 멀티 아키텍처 이미지를 빌드했습니다.

02

여러 저장소의 변경을 하나의 배포 흐름으로

프론트엔드나 백엔드 변경이 인프라 저장소의 워크플로를 호출하도록 연결했습니다. 이미지 빌드·배포와 서비스 health check를 묶고, DB 준비 이후 애플리케이션이 시작되게 했습니다.

03

일반 요청과 실시간 채팅을 같은 도메인에서

Nginx에서 API 경로와 Socket.IO의 WebSocket 업그레이드를 함께 처리했습니다. 프론트엔드·API·채팅의 접근 경로를 서비스 도메인 아래 정리했습니다.
