01 / OVERVIEW

어떤 프로젝트인가요?

세 대의 서버에서 운영하는 개인 서비스의 상태와 배포를 관리하는 컨트롤 플레인입니다. 서버 접속을 반복하는 대신 웹 화면에서 상태를 확인하고 운영 변경을 수행하도록 구성했습니다.

  1. 01서버 · 서비스 상태
  2. 02운영 화면 · 변경 승인
  3. 03배포 · 상태 확인

02 / ENGINEERING

구현과 판단

01

교체하기 전에 새 버전이 준비됐는지 확인

새 배포의 헬스체크를 확인한 뒤 트래픽을 전환하는 흐름을 만들었습니다. 애플리케이션뿐 아니라 라우팅 설정이 기존 서비스를 망가뜨리지 않는지도 운영 중 다뤘습니다.

02

바뀌는 네트워크 환경까지 운영 대상에 포함

터널과 사설 네트워크를 연결하고 IP 변경으로 깨지는 경로를 복구하는 흐름을 구성했습니다. 서버 상태, 인스턴스와 배포 내역을 함께 확인하게 했습니다.

03

에이전트의 요청과 실행 권한을 분리

에이전트가 제안한 운영 변경을 승인한 뒤 적용하도록 하고, 변경 내용을 추적할 수 있게 했습니다. 조회와 실제 인프라 수정의 권한 경계를 구분했습니다.

03 / INTERFACE

04 / OUTCOME

결과와 범위

mini-arcade 등 개인 프로젝트를 실제로 배포하며 운영 요구를 반영한 도구입니다.
