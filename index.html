    05문제 해결

    원인을 끝까지 따라가서 푼 문제들

    고친 뒤에는 같은 문제가 다시 생기지 않도록 테스트나 배포 절차에 검사를 남겼습니다.

    정합성 · 마블워크

    쿠폰과 환불이 함께 나가던 경로

    상황
    기프티콘 발행 API 호출이 트랜잭션 안에 있어, 응답만 유실돼도 실패로 보고 포인트를 환불했습니다. 재시도는 새 거래 ID로 나가 중복 발행까지 가능했습니다.
    원인
    거절, 응답 유실, 결과 미확인이라는 서로 다른 실패를 하나로 처리하고 있었습니다.
    조치
    포인트를 먼저 예약해 커밋하고, 외부 호출은 트랜잭션 밖에서 고정 거래 ID로 보냅니다. 응답이 없으면 보류로 두고 배치가 거래 ID로 재조회해 확정합니다.
    결과
    출시 전 AI 교차 코드 리뷰에서 잡아 고쳤습니다. 티켓 발행 · 회수와 어드민 취소 환불도 같은 원장 규칙을 따릅니다.

    설계 · 마블워크

    정책이 바뀔 때마다 배포하던 구조
